# Teddy's Word Quest

Static vocabulary learning and assessment app for GitHub Pages.

Start with `PROJECT.md` for the product definition. See
`docs/VOCABULARY_SETS.md` for the complete initial 406-word inventory
and `docs/ADDING_VOCABULARY.md` for the workflow for adding future
vocabulary sets.

`index.html` is the current v16 baseline application. The `data/`
directory formalizes the vocabulary corpus separately so future
development can migrate the app away from a hard-coded vocabulary array
without losing source data.
