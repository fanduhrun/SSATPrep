Test

Choose scored or practice, then set difficulty, size, and word selection.

Scored Tests track graded attempts, correct answers, misses, and mistaken choices. Practice uses the same question engine and Coach Mode but does not change Progress. “Needs practice” uses actual misses; “Not yet tested” means zero graded attempts.

⚡ Challenge Mode

Uses context, fill-in-the-blank, antonyms, reverse meanings, and closer distractors.

Challenge: harder questions, no analogies. God Mode: adds explicit synonym/antonym analogies and the toughest distractors.

Progress & Rewards

Stars: 70% = ★, 85% = ★★, 95%+ = ★★★. Challenge at 90%+ earns a bonus ★. God Mode at 85%+ earns a bonus ★.
